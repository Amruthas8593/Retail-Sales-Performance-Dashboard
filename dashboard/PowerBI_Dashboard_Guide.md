# Power BI build guide

Import `data/retail_sales_50000.csv`. Use the Power Query steps, DAX measures and page specification in `powerbi/`.

Build an overview with revenue, profit, units sold and transactions. Add product/category rankings, region/channel comparisons and monthly revenue and profit trends. Use a Date table for month-over-month measures.

Calculate profit margin as total profit divided by total revenue. Reconcile headline totals against the source CSV.

A native Power BI `.pbix` file is not included; this repository provides the import query, measures and build instructions.
